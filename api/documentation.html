📘 API – Simulation de Prime Prêt

🔗 Endpoint

POST https://apimain.yakoafricassur.com/api/simulateur/prime/pret

🎯 Description

Cette API permet de calculer la prime d’assurance d’un prêt en fonction du montant du prêt et de la formule choisie (Gard Or ou Cash Auto).

📥 Paramètres attendus

Champ Type Obligatoire Description
montant_pret number Oui Montant du prêt (≥ 1)
formule string Oui Gard Or ou Cash Auto

⚠️ Règles métier

  • Taux : 0,35 %
  • Durée maximale : 6 mois
  • Gard Or : montant ≤ 5 000 000 FCFA
  • Cash Auto : montant ≤ 10 000 000 FCFA

📤 Exemple de réponse (succès)

{
  "success": true,
  "formule": "Gard Or",
  "montant_pret": 2000000,
  "taux": "0,35 %",
  "duree_max": "6 mois",
  "prime": 7000
}
